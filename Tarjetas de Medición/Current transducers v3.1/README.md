# Current transducers v3.1
    
Esta tarjeta está diseñada para la medición de señales de corriente que provienen desde otros módulos o sensores del equipo. Su función principal es adaptar estas señales para que puedan ser interpretadas correctamente por el sistema de control, asegurando que sean estables y seguras.
