# Voltage transducers v3.1
Tarjeta diseñada para realizar medición y acondicionamiento de señales de voltajes, su función es convertir los voltajes de entrada en señales más pequeñas, estables y seguras para que puedan ser leídas sin riesgo por un sistema de medición.
